# auto_service

Сервисная карта автомобиля на Django: история замен расходников и работ,
средние интервалы (по времени и по пробегу) и план следующего обслуживания
с прогнозом цены.

## Возможности

- Несколько автомобилей у одного пользователя, переключение в шапке страницы.
- Добавление записи: дата, пробег, стоимость; свои пункты работ и расходников.
- Проверка пробега: он не может быть меньше, чем в более ранней записи,
  и больше, чем в более поздней. Текущий пробег машины обновляется сам.
- История записей с редактированием и удалением.
- Интервал считается по датам и по пробегу; следующая замена — по тому,
  что наступит раньше (дата по пробегу оценивается по среднему суточному
  пробегу машины). Просроченные замены подсвечиваются.
- Прогнозная цена: последняя цена + 15% за каждый полный год до замены.

## Локальный запуск

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

`manage.py` по умолчанию использует `config.settings.dev`. Автомобиль
пользователю добавляется в админке: http://127.0.0.1:8000/admin/.

## Тесты

```bash
python manage.py test
python manage.py makemigrations --check --dry-run
```

То же самое запускается в GitHub Actions (`.github/workflows/ci.yml`).
Миграции генерируйте той версией Django, что указана в `requirements.txt`.

## Настройки

Настройки выбираются через `DJANGO_SETTINGS_MODULE`:

- `config.settings.dev` — разработка (по умолчанию для `manage.py`);
- `config.settings.prod` — продакшн (по умолчанию для `wsgi`/`asgi`).

Переменные окружения — в `.env.dev.example` и `.env.prod.example`.
